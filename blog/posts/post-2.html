For decades, talking to a serial port from a web page required a native helper app, a browser extension, or a WebSocket bridge running on the user's machine. The Web Serial API changes that — at least in Chromium-based browsers. It lets a web page open a serial port directly, with the user's explicit permission.

Browser Support

As of 2026, Web Serial is available in:

  • Google Chrome 89+
  • Microsoft Edge 89+
  • Opera 75+

Firefox and Safari do not support it. The API requires a secure context (https:// or localhost).

How It Works

// 1. Request a port (shows a browser picker dialog)
const port = await navigator.serial.requestPort();

// 2. Open it
await port.open({ baudRate: 9600 });

// 3. Read incoming data
const decoder = new TextDecoderStream();
port.readable.pipeTo(decoder.writable);
const reader = decoder.readable.getReader();

while (true) {
    const { value, done } = await reader.read();
    if (done) break;
    console.log('RX:', value);
}

// 4. Write data
const encoder = new TextEncoderStream();
encoder.readable.pipeTo(port.writable);
const writer = encoder.writable.getWriter();
await writer.write('AT\r\n');

Integration with xterm.js

Once you have the reader and writer streams, piping them through xterm.js is straightforward: incoming data goes to term.write(), and xterm keyboard input goes to writer.write(). 

// Display incoming serial data in xterm
(async () => {
    while (true) {
        const { value, done } = await reader.read();
        if (done) break;
        term.write(value);          // raw bytes → terminal display
    }
})();

// Send xterm keyboard input to serial port
term.onData(data => writer.write(data));

This gives you a functional serial terminal in the browser — suitable for debugging microcontrollers, talking to GPS modules, or configuring network equipment over a console port.

Baud Rate and Port Options

port.open() accepts the following options: 

await port.open({
    baudRate:  115200,   // bits per second
    dataBits:  8,        // 7 or 8
    stopBits:  1,        // 1 or 2
    parity:    'none',   // 'none' | 'even' | 'odd'
    bufferSize: 255,
    flowControl: 'none'  // 'none' | 'hardware'
});

Click [ SERIAL PORT ] to Try It

The terminal window in this blog has a [ SERIAL PORT ] button in its toolbar. Clicking it calls navigator.serial.requestPort(). If you're on Chrome with a device connected, you'll see it listed in the picker. Select it and the terminal will switch into serial passthrough mode.
